# Logo

- `logopmii.png`, `pmii-trisakti.png`: file asli dari panitia (sumber).
- `pmii.webp`, `pmii-trisakti.webp`: versi kecil (tinggi 120 px) yang dipakai di header `index.html`.
- `favicon.png`: ikon tab browser (64×64), dibuat dari logo PMII Trisakti.

Untuk mengganti logo, timpa file `.webp` dengan nama yang sama. Jangan menggambar ulang atau memodifikasi logo resmi.
